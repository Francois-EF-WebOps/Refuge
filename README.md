# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/drive/1dU46WGyJNWPql39ZPSIuc40z_NiQJLcO

## Security status

AI analysis is disabled in this browser-only build. Do not add a provider key to client-side configuration or browser bundles. Re-enable the feature only after implementing and testing an authenticated server-side proxy.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Run the static application without an API key.
3. Run the app:
   `npm run dev`
