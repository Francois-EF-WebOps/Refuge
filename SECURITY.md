# Security Policy

## Supported Versions

Only the latest version of the Mascarene Refuge Hypothesis S01 Explorer is supported.

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it via private communication. Do not disclose vulnerabilities publicly until they have been addressed.

**Note on API Keys:** This application uses the Google Gemini API. Ensure that the `API_KEY` provided via environment variables is kept secure and never committed to version control.
